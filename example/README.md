# Example

Install the CLI from a checkout:

```bash
dart pub get
dart run bin/flutter_easy_setup.dart --version
```

After `dart pub global activate flutter_easy_setup`, the same command is `fes --version`.

Run `fes` with no arguments for the menu. Scripted install:

```bash
fes install --flutter-version 3.24.5 --channel stable --dry-run
```
